**MinerU 文档批量处理工具 — 图形化界面**

## ✨ 功能特性

### 📥 文件管理
| 功能 | 说明 |
|------|------|
| **多文件添加** | 支持 Ctrl/Shift 多选，一次添加多个文件 |
| **文件夹导入** | 递归扫描文件夹内所有支持格式的文档 |
| **文件列表管理** | 查看文件大小、状态，支持移除/清空操作 |
| **文件校验** | 启动时自动拦截超过 200MB 或超过批量 200 个限制的文件 |
| **广泛格式支持** | PDF、Word、Excel、PPT、图片、文本、电子书、压缩包等 |

### 🔧 处理选项
- **解析模型** — 3 种符合官方 API 的模型可选
  - `pipeline`（通用解析）
  - `vlm`（高精度，推荐）
  - `MinerU-HTML`（HTML 专用）
- **OCR 文字识别** — 对扫描件和图片文档自动进行文字识别（仅 pipeline/vlm 有效）
- **公式识别** — 自动提取文档中的数学公式
- **表格识别** — 识别并结构化文档中的表格内容
- **多语言支持** — 中文、英文、日文、韩文、法文、德文等 12 种语言

### 💾 输出格式
- **Markdown + JSON** — 默认以 Zip 压缩包形式返回
- **DOCX** — 额外导出 Word 文档格式
- **HTML** — 额外导出网页格式
- **LaTeX** — 额外导出学术排版格式
- **保存全部** — 解压 Zip 并将 Markdown / 图片提取到目录

### 📁 三种输出模式
| 模式 | 说明 |
|------|------|
| **📁 平铺（推荐）** | 所有 `.md` 文件直接放置在输出目录，清爽直观 |
| **📂 独立子目录** | 每个文件一个独立子目录（适合文件多需分类时） |
| **🗜 保留原始 Zip** | 保存 API 返回的原始 Zip 压缩包 |

### 🎨 用户界面
- 标签式布局，功能分区清晰
- 实时进度条 + 每文件状态更新
- 深色主题日志控制台，彩色高亮
- 内置帮助文档

## 🚀 快速开始

### 前置要求
- **Python 3.8+**
- **MinerU API Token** — 前往 [mineru.net](https://mineru.net) 注册获取

### 安装

```bash
# 1. 安装 MinerU SDK
pip install mineru-open-sdk

# 2. 克隆仓库
git clone https://github.com/B0Y-Studio/MinerU-Batch.git
cd MinerU-Batch

# 3. 运行程序
python MinerU_Batch_Processor.py
```

Windows 用户也可以直接双击 **`启动工具.bat`** 运行。

### 环境变量（可选）
```bash
# 设置 Token 环境变量，程序启动时自动读取
export MINERU_TOKEN=your_token_here
```

## 📖 使用指南

### 基本流程

1. **填写 Token** — 在 API 配置区输入你的 MinerU Token
2. **添加文件** — 点击「添加文件」或「添加文件夹」导入文档
3. **配置输出** — 勾选需要的格式，选择输出模式和目录
4. **开始处理** — 点击「开始处理」，等待处理完成
5. **查看结果** — 处理完成后在输出目录中查看

### 输出目录结构

**📁 平铺模式（推荐）** — 所有文件直接放在输出目录：
```
MinerU_Output/
├── 论文1.md
├── 论文1_images/
│   ├── img_001.png
│   └── img_002.png
├── 论文2.md
├── 论文2_images/
├── 报告.docx
└── 报告.html
```

**📂 独立子目录模式：**
```
MinerU_Output/
├── 论文1/
│   ├── 论文1.md
│   ├── 论文1.docx
│   └── images/
├── 论文2/
│   ├── 论文2.md
│   └── images/
└── ...
```

**🗜 保留原始 Zip 模式：**
```
MinerU_Output/
└── zips/
    ├── 论文1.zip
    ├── 论文2.zip
    └── ...
```

### 支持的文件格式

| 类别 | 格式 |
|------|------|
| 文档 | PDF, DOC, DOCX, PPT, PPTX, XLS, XLSX |
| 图片 | JPG, JPEG, PNG, BMP, TIFF |
| 文本 | TXT, MD, HTML, HTM |
| 电子书 | EPUB, MOBI |

| 限制项 | 限制值 |

## ⚙ 高级用法

### 自定义 Base URL
如果需要使用私有部署的 MinerU 服务，可以在界面中修改 Base URL。

### 模型选择
| 模型 | 适用场景 |
|------|----------|
| **pipeline（默认）** | 通用解析模型，适合大多数文档 |
| **vlm（推荐）** | 基于视觉语言模型的高精度解析，效果更好 |
| **MinerU-HTML** | HTML 格式输出的专用模型，仅解析 HTML 文件 |

### SDK 兼容性
本工具已内置 SDK 补丁（Monkey Patch），解决了 `model_version` 字段兼容性问题：
- 移除了导致 `-10002` 错误的 `model_version` 字段（默认不发送）
- 仅在用户明确选择 `vlm` 或 `MinerU-HTML` 时发送
- 避免向 API 发送 `null` 值参数

## ❓ 常见问题

**Q: 如何处理 Token？**
A: Token 可在界面上直接输入（支持密码遮挡显示），也可以设置在 `MINERU_TOKEN` 环境变量中。

**Q: 文件处理失败怎么办？**
A: 查看「运行日志」Tab 获取详细错误信息。常见原因：文件过大、页数超限、Token 配额不足。

**Q: 支持并发处理吗？**
A: SDK 底层使用异步提交 → 轮询模式，支持批量提交后同时轮询。单次最多批量提交 200 个文件。

**Q: 输出文件在哪里？**
A: 默认输出到桌面 `MinerU_Output` 目录，可在界面中自定义。

**Q: 三种输出模式有什么区别？**
A: 平铺模式将每个文件的 `.md` 直接放在输出目录（最清爽）；子目录模式每个文件单独建文件夹（便于分类）；Zip 模式保存 API 返回的原始压缩包（与原官网体验一致）。
